# young-man-eight
The Q and A between the 8th young man and Buddha the Self-Enlighten One
# เหมกมาณพปุจฉา (Hemaka Manava Puccha) 🪷

> **ปุจฉาที่ ๘ จาก โสฬสปัญหา ปารายนวรรค สุตตนิบาต ขุททกนิกาย พระสุตตันตปิฎก**

โปรเจกต์นี้นำเสนอธรรมวิจารณ์ของ **เหมกมาณพปุจฉา** หนึ่งใน ๑๖ คำถาม (โสฬสปัญหา) ซึ่งสะท้อนถึงการแสวงหาธรรมที่นำไปสู่ความหลุดพ้นอย่างแท้จริง ไม่ใช่เพียงการศึกษาตามตำราหรือตรรกะคาดเดา

---

## 📖 แก่นธรรมหลัก (Core Teachings)

เหมกมาณพได้สะท้อนความเบื่อหน่ายในคำสอนของอาจารย์ยุคก่อนที่เน้นเพียงเรื่องเล่า (อดีต/อนาคต) ซึ่งทำให้จิตฟุ้งซ่าน เขาจึงขอทูลถามธรรมที่เป็นเครื่องถอนตัณหาโดยตรง

1. **การละความเพลิดเพลินในผัสสะ:** พระพุทธเจ้าทรงชี้ว่า หนทางแห่งการดับตัณหา คือการกำจัดความกำหนัดยินดี (ฉันทราคะ) ในสิ่งที่เข้ามากระทบทาง ตา หู จมูก ลิ้น กาย และใจ 
2. **นิพพานในปัจจุบัน (ทิฏฐธรรมนิพพาน):** ผู้ที่เข้าใจและปฏิบัติธรรมนี้ได้ จะเป็นผู้มีสติสมบูรณ์ ดับความเร่าร้อนจากกิเลสได้ตั้งแต่ยังมีชีวิตอยู่ นำไปสู่ความสงบเย็นและล่วงพ้นตัณหาเครื่องผูกพันในโลก

---

## 📂 โครงสร้างไฟล์ (Project Structure)

- `index.html` : หน้าเว็บที่แสดงบทสนทนาถาม-ตอบ ระหว่างเหมกมาณพและพระพุทธเจ้า 
  *ออกแบบ UI/UX โดยคำนึงถึงความงดงามทางศิลปะ เรียบง่าย สงบ และใช้หลัก Typography ที่เอื้อต่อการน้อมจิตพิจารณาธรรม*
- `README.md` : ไฟล์เอกสารอธิบายภาพรวมและสาระสำคัญของโปรเจกต์ (ไฟล์นี้)

---

## 💻 การใช้งาน (Usage)

สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้บนเครื่องคอมพิวเตอร์หรือสมาร์ทโฟน เพื่อเข้าถึงเนื้อหาพระธรรมที่จัดหน้าไว้อย่างประณีต ธรรมบทนี้สั้น กระชับ แต่อัดแน่นด้วยแก่นของการเจริญสติปัฏฐานเพื่อตัดกระแสแห่งตัณหา
